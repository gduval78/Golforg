1 Golforg 是什么？

Golforg 帮助组织者举办一天或多天的高尔夫赛事。你录入球员和球场，设定日程，给小组抽签，打印记分卡，然后录入成绩——可以用按钮，也可以扫描用铅笔填写的卡片。排名会自动更新，并可导出为 PDF。

所有数据都保存在你的 iPhone 上。无需账号，无需服务器，球场上也不需要联网。相应地，备份由你自己负责（见“备份与恢复”）。

  • 比杆赛：总杆和净杆排名，外加推杆排名。
  • Stableford：每洞计分，分净杆和总杆。
  • Shamble 和 Scramble：团队赛制，按小组和按天排名，并有总排名。

2 快速入门

  1. 添加球员（首页 → 球员）。
  2. 添加球场，设置标准杆和指数（首页 → 球场）。
  3. 用 + 按钮创建赛事。
  4. 为赛事报名球员并设定日程：每天一个球场和一种赛制。
  5. 给小组抽签并打印记分卡。
  6. 用按钮录入成绩，或扫描卡片。
  7. 查看排名并导出为 PDF。
  8. 备份你的数据（首页 → 备份）。

3 球员

首页 → 球员 → +。球员包括名、姓和 0 到 54 的差点（可含小数）。姓名显示为“名 姓（大写）”。

要一次录入很多球员，请使用导入名单：每行一名球员，名 姓 ; 差点，例如 John SMITH ; 13 或 John ; Smith ; 13。已存在的球员（同名）只会更新差点。

4 球场

首页 → 球场 → +。给球场起个名字（也可填写国家），然后为 18 个洞分别设置标准杆（3 至 5）和指数（1 至 18，每个只用一次）。

指数决定在哪些洞让杆。它用于净杆成绩和 Stableford。如果某个指数重复，App 会提醒你。

5 创建赛事

首页 → +。输入名称和天数（1 至 14）。你可以设定第一天：之后的日期是连续的。休息日可以稍后添加。

赛事页面汇集了一切：球员、日程、赛事规则、抽签、各天、排名和 PDF 导出。页面底部的“清除所有成绩”（试玩后很方便）和“删除此赛事”都要求你输入一个确认码。

6 球员与日程

球员：勾选参赛球员。日程：为每一天添加一个球场和一种赛制（比杆赛、Stableford、Shamble 或 Scramble）。同一个球场可以在另一天以不同赛制再次使用。

  • 为多天安排同一球场：一次性给选定的日子设置相同的球场和赛制。
  • 添加球场或休息日：休息日是不打球的一天。
  • 在此日之前插入休息日会给行程增加一天；后续日期会重新编号并顺延，其分组和成绩一并顺延。
  • 修改日期…可移动某一天；选择“同时顺延后续日期”，行程的其余部分也会一起移动。
把某一天安排为 Stableford 会自动创建 Stableford 排名。其他赛制请在按赛制排名中使用“按赛制生成”。

7 赛事规则

  • 捡球：捡球的球员在该洞的总杆和净杆都记标准杆 + N（默认 5），Stableford 记 0 分。在团队赛制（shamble、scramble）中，只有当其他人都没有成绩时，捡球成绩才会计入。
  • 统计推杆：开启后，录入一个洞时会要求填写杆数和推杆数，并可使用推杆排名。关闭时只要求杆数。

8 赛制与计分

  • 净杆 = 杆数减去让杆。球员的差点（四舍五入）分摊到各洞：差点 20 表示每洞让 1 杆，并在指数最低的 2 个洞（1 和 2）再让 1 杆。
  • Stableford（对照标准杆，净杆或总杆）：标准杆 2 分，柏忌 1 分，双柏忌或更差 0 分，小鸟 3 分，老鹰 4 分，信天翁 5 分。捡球记 0 分。
  • Shamble：每洞计小组的最佳净杆。Scramble：计小组的最佳总杆。排名按小组和按天给出，并有按球员的总排名。
  • 名次：总成绩相同者并列（1、1、3）。部分成绩（没有打完所有洞）只有在洞数相同时才可比较。

9 给小组抽签

赛事 → 抽签分组。选择日期（或一次选所有天）和每组人数（2 至 6），然后点生成抽签方案。检查部分会列出未满足的约束。先点一名球员，再点同一天的另一名球员，即可互换。为每一天选择球场，然后点确认并创建分组。

抽签约束用于引导抽签：避免与相同球友再次同组、平衡差点、让某些球员分开或同组、把某位球员固定在某一组、标记某位球员无法参加。每条约束要么是严格的，要么是权重为 1 至 10 的偏好。

重新抽签或取消已有的抽签：App 会显示一个需要你输入的数字（5 分钟内有效）。一旦已有成绩就无法操作：请先清除成绩。

10 记分卡与成绩录入

在抽签页面，待打印的记分卡（PDF）会为每个小组生成一页 A4 横向页面，包含球场、球员和一个二维码。请按 100 % 打印（不要选“适合页面”），并保持四角的 4 个黑色方块清晰可见。

球员用铅笔填写卡片，每格一个数字，字迹清晰。捡球时，请在杆数格中写 R。

用按钮：某天 → 分组。各洞显示在顶部；用 − 和 + 调整杆数和推杆数，需要时打开“捡球”，然后点保存第 N 洞。已保存的行会显示净杆和 Stableford 得分。你可以为整组清除某个洞，也可以向左滑动某位球员的行来清除其成绩。

用扫描：某天 → 扫描记分卡（或分组中的扫描按钮）。拍下整页，要平放、光线充足，二维码和 4 个黑色方块都要可见。App 在手机上读取数字。不确定的格子会显示为橙色或红色：请修正（可只显示待核对的洞），然后点保存成绩。

照片在你的 iPhone 上处理，不会被保存，也不会发送到任何地方。App 会拒绝属于其他赛事、日期或分组的卡片。

11 排名与 PDF

总杆 / 净杆 / 推杆排名累计所有天的成绩。按赛制排名（Stableford、shamble、scramble）可限定于某些球场、日期或赛制；使用按赛制生成创建常用排名，或点 + 创建自己的（包括自定义 Stableford 计分）。

导出为 PDF：勾选想要的排名，生成 PDF 并分享（邮件、信息、AirPrint 等）。

12 备份与恢复

你的数据只存在于这部手机上。请定期备份：首页 → 备份 → 立即备份，然后在“文件”App 中选择保存位置（建议 iCloud 云盘）。如果一周没有备份，首页会出现提醒。

要恢复（换新手机或出现问题后）：备份 → 恢复备份…，选择文件。App 会显示其中的内容，并替换手机上的全部数据；之前的状态会单独保留一份，以防万一。

13 语言、支持与隐私

首页 → 设置与帮助：选择语言（英语、法语、德语、西班牙语、意大利语、葡萄牙语、简体中文、俄语；默认跟随手机语言），联系支持（邮件包含技术信息，但绝不包含姓名），查看诊断日志，打开本指南或隐私政策。

Golforg 不收集任何数据。请阅读隐私政策。

14 故障排除

问题可能原因解决办法
扫描器找不到二维码或四角的方块整页没有完全入镜，或照片模糊、太暗拍下整页，平放，光线充足，包括四个角
有些数字读错了铅笔太淡或字迹不清在核对时修正橙色/红色格子；下次写得更重一些，每格一个数字
“此卡片属于另一场赛事 / 另一天 / 另一组”拿错了卡片，或在错误的日期扫描打开正确的日期和分组，或换用正确的卡片
无法重新抽签或取消抽签已经有成绩先清除成绩（某个洞，或“清除所有成绩”）
某个赛制没有排名该排名尚未创建按赛制排名 → 按赛制生成
我的数据不见了（换手机、重装）数据只存在于手机上备份 → 恢复备份…，使用你最近的文件
被要求填写推杆，但我不统计推杆“统计推杆”已开启赛事规则 → 关闭“统计推杆”
